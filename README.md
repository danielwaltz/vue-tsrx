# vue-tsrx

POC of a Vue Vapor app using [TSRX](https://tsrx.dev/) template syntax.

Enables all available tooling, including ESLint, Prettier, and TypeScript integration.

Uses [Vite](https://vitejs.dev/), [Tailwind](https://tailwindcss.com/) with [DaisyUI](https://daisyui.com/), [VueUse](https://vueuse.org/), and [Nitro](https://nitro.build/) with [Pinia Colada](https://pinia-colada.esm.dev/) to test data fetching and validate Vue package ecosystem compatibility.

## Usage

```bash
pnpm install
pnpm dev
```
