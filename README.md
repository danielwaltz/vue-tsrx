# vue-tsrx

POC of a Vue Vapor app using [TSRX](https://tsrx.dev/) template syntax.

Enables all available tooling, including ESLint, Prettier, and TypeScript integration.

Uses [Vite](https://vitejs.dev/), [Vue Router](https://router.vuejs.org/) with file-based routing, [Unhead](https://unhead.unjs.io/), [Tailwind](https://tailwindcss.com/) with [DaisyUI](https://daisyui.com/), [VueUse](https://vueuse.org/), and [Nitro](https://nitro.build/) with [Pinia Colada](https://pinia-colada.esm.dev/) to test data fetching and validate Vue package ecosystem compatibility.

Tracking this Vue Router PR for official Vapor support: https://github.com/vuejs/router/pull/2509

Preview available: https://vue-tsrx.vercel.app/

## Usage

```bash
pnpm install
pnpm dev
```
